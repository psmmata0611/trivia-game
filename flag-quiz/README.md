# Flag "THE FLAG" – Geography Quiz Website

A browser quiz game where you answer flag and geography questions by picking the right country map. Built for my second-year university coursework (2024/25).

## Features
- 12 timed questions (10 seconds each) with shuffled answer options
- Sign-up and login with form validation (regex checks, matching passwords, date of birth check)
- Results page showing your answer vs. the correct one for every question
- Leaderboard ranking every player by their best score
- Data stored in the browser with `localStorage` / `sessionStorage`

## Tech
HTML, CSS, JavaScript (ES6 classes and modules)

## How to run
Open `index.html` in a browser, or play the live version on GitHub Pages.

> Note: this is a front-end-only project, so accounts are stored in the browser and passwords are not encrypted. A real app would use a server and a database.
